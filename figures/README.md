# Engineering Study Guide Figure Set

This package contains 35 textbook-ready figures generated from `figure-log.csv`.

## Contents

- `png/` — high-resolution raster figures, 2400 pixels wide
- `svg/` — editable vector masters with embedded accessibility descriptions
- `figure-manifest.csv` — figure ID, chapter, section, type, description, alt text, and file paths
- `figure-manifest.json` — the same manifest in structured JSON format

Every PNG and SVG is named with the Figure ID from Column A. The visual treatment uses a consistent navy, blue, teal, amber, red, and purple educational palette on a white background.

The SVG `<desc>` element for each figure contains the Alt Text from Column F.
